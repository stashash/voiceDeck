# T-24. Воспроизводимый запуск: контейнер сервиса и конфиг

Модель: sonnet. Волна 5. Зависит от слитых T-12, T-13, T-14.

## Цель

Эксперт клонирует репозиторий, правит один файл настроек и одной командой поднимает всё: сервис `designer`, Java-сервис живого режима, базу. ТЗ требует воспроизводимый сетап и запуск конфиг-файлом. PDF и картинки слайдов в контейнере делает LibreOffice, PowerPoint экспертам не нужен.

## Файлы

Только эти файлы, других не трогать:

- `designer/Dockerfile`, `designer/.dockerignore` (новые)
- `designer/src/designer/settings.py` (новый), `designer/config.example.yaml` (новый)
- `designer/tests/test_settings.py` (новый)
- `compose.yaml`, `.env.example`

## Что сделать

1. `settings.py`: настройки из файла YAML (путь в `DESIGNER_CONFIG`, по умолчанию `config.yaml` рядом с запуском), поверх него переменные окружения. Поля: адрес и имя модели, адрес и имя модели для живого режима (может отличаться), каталог данных, порт, разрешённые адреса для CORS, движок конвертера, число слайдов по умолчанию, какие варианты строить. `config.example.yaml` с комментариями по-русски. Уже существующие переменные `DESIGNER_*` продолжают работать.
2. Растеризацию PDF в PNG через `pdftoppm` в `convert.py` пишет параллельная задача T-26: здесь нужно только поставить в образ пакет poppler-utils.
3. `designer/Dockerfile`: python 3.12 slim, LibreOffice Impress без графической оболочки, poppler-utils, шрифты с кириллицей (Liberation, DejaVu), установка пакета из `pyproject.toml`, непривилегированный пользователь, запуск `python -m designer serve`. Каталог данных томом.
4. `compose.yaml`: сервис `designer` на порту 8090 (наружу только `127.0.0.1`), том данных, `extra_hosts` для доступа к модели на хосте (`host.docker.internal`), переменные модели. Сервис `app` получает `DESIGNER_URL=http://designer:8090`. Существующие сервисы и их переменные не ломать.
5. `.env.example`: новые переменные с короткими комментариями.

## Готовность

Из каталога `designer`: `python -m pytest tests/test_settings.py`. Проверки: файл настроек читается, переменная окружения перекрывает файл, неизвестное поле даёт понятную ошибку.

Из корня репозитория: `docker compose config` проходит без ошибок. Образ собирается: `docker build -t voicedeck-designer designer` (сборка занимает несколько минут, запускать синхронно). Проверка внутри образа: `docker run --rm voicedeck-designer python -c "from designer.export import convert; print(convert.available())"` печатает список с `libreoffice`.
