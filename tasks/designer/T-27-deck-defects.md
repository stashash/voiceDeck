# T-27. Дефекты живой колоды на шаблоне VK Tech

Модель: opus. Волна 6. Зависит от слитых волн 1–4. Идёт параллельно с волной 5: файлы не пересекаются.

## Цель

Живая колода на шаблоне VK Tech (бриф про потоковые отчёты, Qwen3.8-27B, три варианта) собирается, но на глаз видно брак. Слайд «крупное число» стоит без числа. Текстовый слайд лёг на образец диаграммы Ганта, цветные полосы образца остались. Диаграмма встала поверх водяных номеров «01 02 03 04» от карточек образца. У карточек остались точки-маркеры без текста. После этой задачи те же три колоды выглядят чисто.

Материалы лежат вне git, каталог назван в задании исполнителю: листы слайдов `vk-tech-variant-a.jpg`, `vk-tech-variant-c.jpg`, `workspace-first-live.jpg`, сама колода `vk-tech-variant-a.pptx` и её состояние `vk-tech-variant-a.deck.json` (план, инструкции, сцены, находки). Начни с просмотра листов глазами и сопоставь каждый дефект со сценой и инструкцией в json.

## Файлы

Только эти файлы, других не трогать:

- `designer/src/designer/parse/patterns.py`, `designer/src/designer/parse/geometry.py`
- `designer/src/designer/layout/match.py`, `capacity.py`, `compose.py`, `scene.py`
- `designer/tests/parse/test_patterns.py`, `test_geometry.py`
- `designer/tests/layout/test_match.py`, `test_capacity.py`, `test_compose.py`, `test_scene.py`

`contracts.py` уже расширен, менять его не надо: у `Pattern` появилось поле `decor: list[DecorShape]` (фигура оформления с рамкой и видом). Прежнее `decor_shape_ids` остаётся. Экспорт pptx не менять: он исполняет `SlideSpec` буквально, все решения принимаются в вёрстке.

## Что сделать

1. Разбор заполняет `Pattern.decor` рамками и видом каждой фигуры оформления (фигура, картинка, линия, текст).
2. Крупное число без числа (лист a, слайды 4 и 8; лист c, те же). Найди по json, куда делось значение: слот `number` остался пустым, число ушло в заголовок либо слот получил кегль, при котором строка не видна. Исправь причину в вёрстке. Проверка: у слайда `big_number` значение из намерения стоит в слоте с ролью `number`, кегль не ниже ступени `title`.
3. Образец-диаграмма из фигур (лист a, слайд 3: полосы Ганта). Паттерн, где оформление образует ряд из трёх и больше цветных полос или столбиков разной длины на общей оси, это образец диаграммы: разбор ставит ему область `chart` по общей рамке этих фигур. Подбор уже не берёт паттерны с чужой диаграммой под намерение без диаграммы.
4. Оформление в рамке визуализации (лист a, слайд 7: водяные номера под диаграммой). Фигуры оформления, которые лежат внутри `viz_box` больше чем наполовину своей площади, уходят в `remove_shape_ids`. Фон на весь кадр, логотип и колонтитул не трогать.
5. Маркеры без текста (лист a, слайды 11 и 12: точки без строк). Если текстовый слот блока получил пустую строку, мелкие фигуры оформления того же блока, стоящие на одной линии с этим слотом (маркер, значок строки), уходят в `remove_shape_ids`. Если пустыми остались все текстовые слоты блока, блок убирается целиком.
6. Карточки без пояснений (лист a, слайд 2 и 12: заголовок карточки есть, пояснение мелкое или пустое). Пояснение пункта из намерения должно попадать в слот `body` блока; если слота `body` нет, пояснение присоединяется к заголовку через перевод строки и кегль подгоняется.

## Готовность

Из каталога `designer`:

```
python -m pytest tests/parse/test_patterns.py tests/parse/test_geometry.py tests/layout
```

Прежние проверки остаются зелёными. Новые проверки на выданных шаблонах (фикстура `templates`): у каждого паттерна `decor` покрывает все `decor_shape_ids`; в шаблоне VK Tech слайд с полосами Ганта получил область `chart`; план из восьми намерений (тот же, что в прежних тестах вёрстки) на всех трёх шаблонах даёт слайд `big_number` с числом в слоте `number`; у слайда с диаграммой в сцене нет элементов оформления внутри `viz_box`, кроме фона; в сценах нет блоков, у которых все текстовые элементы пусты.

После своих тестов собери колоду без модели и посмотри её глазами. Команда: `Set-Location <рабочее дерево>/designer; $env:PYTHONPATH='src'; & <python> -c "..."` с планом из восьми намерений, `build_package`, `choose_pattern`, `compose`, `export_pptx`. Картинки слайдов через PowerPoint в этой задаче снимать не нужно: сверяй по сценам и по числу фигур в итоговом pptx.

## Запреты

- Никаких имён шаблонов, макетов, номеров слайдов и текстов-образцов в коде, номера только в тестах.
- Модели и сеть не использовать, PowerPoint не запускать.
- Полный набор тестов не гонять, только свои файлы.
