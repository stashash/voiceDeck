# Формат разметки калибровочного корпуса

Каждый монолог = 2 файла в одной папке:

    corpus/<name>/transcript.tsv     # предложения
    corpus/<name>/boundaries.tsv     # границы

## transcript.tsv

TSV, одна строка = одно предложение, UTF-8:

    0	Сегодня мы обсудим архитектуру решения.
    2400	Аудио обрабатывается локально на устройстве.

Колонки: start_ms (целое, мс от начала записи), text (предложение целиком).

Индекс предложения = номер строки минус 1 (0-based). Порядок строк = порядок в записи.

## boundaries.tsv

TSV, одна строка = одна граница темы:

    7	slide
    12	slide

Колонки: sentence_index (индекс предложения, с которого начинается НОВАЯ тема), kind (всегда slide; зарезервировано).

Первое предложение (индекс 0) границей не является.

## Проверка

    node scripts/calibrate/calibrate.mjs corpus/<name>

Валидирует формат, считает метрики и печатает отчёт.
