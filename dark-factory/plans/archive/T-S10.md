# T-S10 — Калибровка coalesce threshold под bge-m3

**Epic:** E-S · **Risk:** low · **Pipeline:** solo · **Human gate:** none
**Зависит от:** T-S1, T-S12 (нужны калибровочные числа)

## Контекст

Старый coalesce threshold 0.5 для MiniLM. После замены на bge-m3 ожидаемый диапазон 0.62–0.72. Без калибровки coalesce будет либо молчать, либо ложно клеить.

## Что меняться

- `Session.coalesce()` threshold из `models/config.json` (поле `coalesceThreshold`, default 0.65).
- `continuation` эвристика (нет точки в конце) остаётся.
- related cosine — из config, не хардкод.

## Acceptance

- Тест: на синтетическом распределении (заранее заданные эмбеддинги) coalesce срабатывает при `cosine > 0.65` и НЕ срабатывает при `< 0.55`.
- Coalesce лимит слов поднят до 250 (связь с T-S5).
- Порог в config, не в коде.
