# Голосовой редактор

Адрес: http://localhost:8088/#/voice-editor. Существующий /live сохраняет сценарий генерации смысловых слайдов из выступления.

## Работа

1. Выберите дизайн-систему. Создайте слайд или элементы кнопками.
2. Включите микрофон и разрешите доступ браузеру. Режим «Управляю» выполняет команды, «Диктую текст» дописывает речь в выделенный текстовый объект.
3. Для проверки без микрофона введите ту же команду в поле под холстом.
4. Документ автоматически сохраняется в localStorage этого браузера. Скачивание JSON — резервная копия; HTML — просмотр презентации.
5. «Открыть экран зала» показывает опубликованный слайд. «Покажи залу» обновляет его. В режиме показа голос принимает только «Следующий слайд» и «Предыдущий слайд».

## Быстрые команды без LLM

- Добавь заголовок План запуска
- Создай три карточки
- Выбери номера два и три
- Вправо на двадцать
- Ещё немного
- Половину назад
- Замени текст на Запуск в октябре
- Ширина 320
- Высота 240
- Размер текста 32
- Сделай акцентным
- Одинаковая высота
- Выровняй по верхнему краю
- Распредели по горизонтали
- Сгруппируй / Разгруппируй
- На передний план / На задний план
- Удали / Дублируй
- Отмени / Повтори
- Новый слайд / Следующий слайд / Предыдущий слайд
- Стоп

Свободные команды уходят агенту Live через /editor/intent. Например: «Добавь таблицу с колонками Команда и Срок, строками Дизайн — октябрь и Разработка — ноябрь». Геометрия таких запросов пока задаётся моделью и проверяется исполнителем.

«Найди изображение гор» использует Wikimedia Commons (нужен интернет). «Сгенерируй изображение гор» требует отдельно настроенного Automatic1111. Модель для текста не генерирует изображения.

## Контракты и надёжность

WebSocket editor_mode переключает сессию ASR на editor_utterance: целая финальная фраза с уникальным utterance_id, без смысловой сегментации и фоновой генерации слайдов. Повторные события отбрасываются. Пауза/возобновление используют ту же сессию.

Быстрые операции применяются синхронно. Новый модельный запрос отменяет предыдущий. «Стоп» прерывает ожидание HTTP и запрещает применение позднего результата. Это не гарантирует прекращение вычислений внутри внешнего сервера модели. Если документ изменился во время планирования, ответ не применяется. План атомарный, одна запись отмены.

## Границы текущей реализации

- ASR остаётся существующим GigaAM/sherpa offline-декодером с промежуточными результатами, а не новым потоковым движком.
- Хранение редактора пока браузерное; объединение с серверным каталогом колод, загрузка JSON и редактируемый PPTX-экспорт требуют следующего этапа.
- Нет маленькой модели-маршрутизатора, потокового превью плана и постоянных связей макета.
- Параметры шрифта/цвета и существующие шаблоны дизайн-систем применяются; универсальный constraint-layout ещё не реализован.
- Скорость с реальным микрофоном и конкретным пользователем не измерена. Автотесты не заменяют проверку дикции, пауз и фонового шума.
