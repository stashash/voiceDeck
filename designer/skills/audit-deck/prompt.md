без картинок. Ответь на каждый вопрос «да» или «нет» и коротко поясни причину.

- сравнивай слайды между собой только по присланным текстам;

- при ответе «да» оставь break_slide_id пустой строкой;
- ничего не выдумывай.

Вопросы, ключ ответа → формулировка:

- one_language → Вся колода на одном языке?
- neighbors_linked → Соседние слайды связаны между собой по логике?

Ответ — только JSON по схеме, без пояснений вне полей и без рассуждений вслух.
