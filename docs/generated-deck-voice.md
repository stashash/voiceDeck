# Голосовая правка готовых презентаций

Откройте «Презентации» → карточку в «Мои презентации» → «Редактировать голосом».
Это редактор исходной колоды, созданной по дизайн-системе: правки сохраняются на сервере, обновляются PPTX, HTML и PDF при доступном конвертере. Отдельный компонентный редактор /voice-editor сохраняет свой прежний сценарий.

## Команды

- «Следующий слайд», «Предыдущий слайд», «Слайд три».
- «Выбери элемент два»: текстовые области обозначены номерами.
- «Замени текст на Новый заголовок»: точная замена выбранного текста без LLM.
- «Сократи заголовок», «Перепиши вывод проще»: запрос агенту по содержанию текущего слайда.
- «Выбери образец два»: применить второй доступный шаблон из правой панели.
- «Добавь слайд», «Скопируй слайд».
- «Удали слайд»: требуется «Да» или «Нет»; последний слайд удалить нельзя.
- «Отмени»: восстановление предыдущего состояния варианта.

Команду можно ввести в поле над холстом: оно использует тот же обработчик. Во время сохранения новая изменяющая команда не ставится в неявную очередь: интерфейс просит повторить её после завершения. «Стоп» не прерывает уже начавшуюся серверную пересборку; дождитесь завершения и скажите «Отмени».

Этот контур редактирует содержание и меняет композицию через образцы исходной дизайн-системы. Произвольное перемещение отдельных фигур голосом в готовом PPTX пока не подключено.

## Каталог

- Новая презентация: новый бриф вверху главной страницы, выбранная дизайн-система и «Создать презентацию».
- «Создать копию»: независимая колода с собственным идентификатором, исходная остаётся без изменений.
- «Удалить»: подтверждение и помещение в корзину.
- «Корзина» → «Восстановить»: возвращение колоды в каталог. Файлы при удалении из каталога физически не уничтожаются.
- Во время генерации копирование и удаление заблокированы.

Каталог показывает все колоды, включая незавершённые и ошибочные, а не только восемь последних.
