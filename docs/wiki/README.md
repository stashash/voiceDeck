# Вики voiceDeck

voiceDeck читает pptx-шаблон как дизайн-систему и собирает по нему слайды двумя путями. По брифу выходит колода в трёх вариантах вёрстки с аудитом и выгрузкой в pptx, HTML и PDF. Из живой речи слайды в стиле шаблона появляются вслед за спикером.
