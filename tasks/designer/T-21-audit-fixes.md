# T-21. Починка находок аудита по выбору человека

Модель: sonnet. Волна 4. Зависит от слитых T-03, T-19.

## Цель

Человек видит находки аудита на слайде, отмечает те, что хочет исправить, и получает слайд без них вместе с отчётом: что изменено и почему. По ТЗ аудит это часть конвейера, а выбор остаётся за пользователем.

## Файлы

Только эти файлы, других не трогать:

- `designer/src/designer/audit/fixes.py`
- `designer/tests/audit/test_fixes.py` (новый)

Сигнатура `apply_fixes` заморожена.

## Что сделать

`apply_fixes(specs, scenes, findings, chosen_ids, ds)` возвращает новые инструкции, новые сцены и отчёт. Входные объекты не меняются. Починки детерминированные:

- `template.type_scale`: кегль элемента и `fitted_size_pt` соответствующего слота ставятся на ближайшую ступень шкалы;
- `template.color`: цвет текста или заливки заменяется ближайшим цветом палитры;
- `layout.text_overflow`: кегль опускается по ступеням шкалы, пока оценка вместимости не сойдётся, но не ниже самой мелкой ступени;
- `layout.off_guides`: левый край элемента сдвигается к ближайшей направляющей, если сдвиг не больше 0,02 и не создаёт наложения;
- `layout.in_margins`: элемент сдвигается внутрь полей, если для этого хватает сдвига до 0,03;
- `template.contrast`: цвет текста заменяется самым контрастным к фону цветом палитры;
- `integrity.placeholder_text`: текст-заглушка очищается в сцене и в `slot_text` либо `unit_text`;
- `density.bullets`: лишние пункты сверх шести убираются из блоков, отчёт называет убранные.

Соответствие элемента сцены и слота инструкции идёт по `source_shape_id` элемента и `shape_id` слота паттерна. Находка, для которой починки нет (контекстные, наложения, пустой слайд), получает в отчёте `skipped` с причиной. После починки вызывающий код заново гоняет аудит: сама функция аудит не зовёт.

## Готовность

Из каталога `designer`:

```
python -m pytest tests/audit/test_fixes.py
```

Для каждой починки тест на синтетической сцене: находка от `run_checks` есть, после `apply_fixes` и повторного `run_checks` этой находки нет, входные объекты не изменились, в отчёте `fixed` и понятное «что изменено». Контекстная находка даёт `skipped`.
