# Задачи сервиса «Цифровой дизайнер презентаций»

Сервис живёт в `designer/` (Python). Слои: разбор, план, вёрстка, аудит, экспорт. Общие контракты в `designer/src/designer/contracts.py`, менять их можно только отдельной задачей. Java-сервис в `backend/` принимает звук и режет речь на смысловые фрагменты; живой режим зовёт тот же сборщик слайда, что и текстовый.

Правила для исполнителя:

- один файл, один владелец: трогать только файлы из раздела «Файлы» своей задачи;
- каждая полоса работает в своём рабочем дереве git и на своей ветке;
- гонять только свои тесты, полный набор идёт один раз перед слиянием;
- промпты и настройки моделей лежат файлами в `designer/skills`, в код не зашиваются;
- в коде нет имён выданных шаблонов, имён макетов и номеров слайдов: на финале будет незнакомый pptx;
- модели только с открытыми весами до 35B, по умолчанию `qwen/qwen3.8-27b` на локальном сервере.
