# T-S13 — Офлайн TextTiling-pass на stop

**Epic:** E-S · **Risk:** medium · **Pipeline:** solo · **Human gate:** optional
**Зависит от:** T-S3, T-S5

## Контекст

После `stop` можно сделать двусторонний проход по всему тексту и пересчитать границы. Реалтайм-ленту это не лечит, но архивный экспорт получает лучшие границы → лучше слайды.

## Что меняется

- `TextTiling.java` — новый класс. Двусторонний алгоритм: similarity-sequence, smoothing window 4, depth-score по всему корпусу.
- `Session.runOfflinePass()` — вызывается из `flush(true)` после `event("stopped", ...)`.
- Применяет результат через серию `chunk_revise` с `source="offline"` (новый приоритет — выше confirmer, ниже human).
- Регенерирует слайды: существующий `generate()` уже это делает, потому что `slide` event требует совпадения `chunk.rev`.

## Acceptance

- `OfflinePassTest`: смоделировать 5 минут монолога с 4 естественными границами → после offline pass чанков 4–5, не 8+.
- Offline pass занимает < 2 с для 10 минут аудио (CPU only).
- Никаких side-effects на event log, кроме `chunk_revise` с `source="offline"`.
- Если LLM/embedder недоступны — pass молча скипается, warning в HUD.
