# T-02. Разбор pptx: слайды-образцы как паттерны

Модель: opus. Волна 1. Самая трудная часть разбора: на ней стоит вся вёрстка. Зависит только от `designer/src/designer/contracts.py`.

## Цель

Система смотрит на слайд чужой презентации и понимает его устройство: где заголовок, какие блоки повторяются, сколько их помещается, куда ставить диаграмму. По этому описанию сборщик потом клонирует слайд, меняет текст, убирает или добавляет блоки. Имён макетов и групп для этого мало: в выданных шаблонах от 74 до 95 % фигур свободные, списки плоские, фигуры названы «Google Shape;774;p58».

## Файлы

Только эти файлы, других не трогать:

- `designer/src/designer/parse/patterns.py`
- `designer/src/designer/parse/geometry.py` (новый)
- `designer/tests/parse/test_patterns.py`, `test_geometry.py` (новые)

Сигнатуры в заготовке заморожены. `contracts.py` не менять: если контракта не хватает, написать об этом в отчёте.

## Что сделать

1. Для каждого слайда собрать плоский список фигур с раскрытием групп (учесть преобразование координат группы), с `shape_id`, типом, рамкой в долях слайда, текстом, стилем первого фрагмента.
2. Размер шрифта искать по цепочке: фрагмент, абзац, фигура, заполнитель макета, мастер. Если не найден, 18 pt.
3. Повторяющиеся блоки. Сигнатура фигуры: тип, ширина и высота с округлением до 0,01, есть ли текст. Фигуры с одной сигнатурой, стоящие с постоянным шагом по x, по y или сеткой, образуют ряд. Ряды с одинаковым числом элементов и одинаковым шагом складываются в блок (`RepeatUnit`). Для группы заполнить `direction`, `cols`, `rows`, `step`, `unit_size`, `units`, `unit_slots`, `unit_areas`, `max_units` (сколько блоков помещается с тем же шагом внутри полей слайда).
4. Слоты: текстовые фигуры вне блоков. Роль `title` у заполнителя заголовка либо у самого крупного верхнего текста, `number` у коротких числовых образцов («01», «43%»), внутри блока `heading` и `body` по кеглю и порядку. `max_chars` и `max_lines` считать от рамки и кегля (средняя ширина знака 0,52 кегля, интерлиньяж 1,2).
5. Области: картинки (`image` или `icon` по размеру), диаграммы и таблицы (`graphicFrame`).
6. Тип слайда (`kind`) правилами по структуре, с `kind_confidence`: крупное число, блоки с номерами это шаги, три и больше блоков «заголовок и текст» это карточки, диаграмма, таблица, цитата, команда (круглые фото с подписями), таймлайн, титул, разделитель, финал. Что не распознано, `other` с низкой уверенностью.
7. Тема слайда `light` или `dark` по яркости фона: заливка слайда, макета, мастера либо средний цвет картинки на весь кадр (Pillow).
8. `decor_shape_ids`: всё, что не слот, не область и не блок.
9. `extract_layouts`: макеты с заполнителями как слотами.

## Готовность

Из каталога `designer`:

```
python -m pytest tests/parse/test_patterns.py tests/parse/test_geometry.py
```

`test_geometry.py` проверяет поиск повторов на синтетических рамках без pptx. `test_patterns.py` идёт на выданных шаблонах (фикстура `templates`, файл искать по подстроке имени) и обязан проверять факты, снятые с файлов:

- «VK Tech», слайд 17: один заголовок и одна группа сеткой 3×2 из шести блоков, в каждом блоке два текстовых слота (образец «Безопасность» и текст под ним), `kind` это `cards`;
- «WorkSpace», слайд 6: группа из трёх блоков в ряд с шагом около 0,30;
- «WorkSpace», слайд 22: группа из четырёх блоков в столбец с шагом около 0,20;
- «WorkSpace»: не меньше 80 % слайдов с темой `dark`; «Education» и «VK Tech»: большинство `light`;
- в каждом шаблоне число паттернов равно числу слайдов, у каждого `shape_id` из паттерна есть фигура на исходном слайде;
- в каждом шаблоне не меньше половины слайдов получили `kind` отличный от `other`;
- сторонний pptx (фикстура `foreign_pptx`) разбирается без исключений;
- один шаблон разбирается быстрее 90 секунд.

## Запреты

- Никаких имён шаблонов, имён макетов, текстов-образцов и номеров слайдов в коде: на финале будет файл, которого мы не видели. Номера слайдов допустимы только в тестах.
- Модели и сеть не использовать: разбор детерминированный.
- Полный набор тестов не гонять, только свои файлы.
