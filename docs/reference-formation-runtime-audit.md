# Проверка формирования презентаций — 20 октября 2026

Найдены и исправлены связанные дефекты:

- Большой справочник автоматически создавал 29 страниц плюс повторный слайд с количеством строк. Теперь по умолчанию один честно обозначенный фрагмент; полный показ выбирается до создания.
- Небольшая таблица с пропусками называлась справочником. Теперь заголовок объясняет различие нуля и пропуска.
- Служебные инструкции о готовых слайдах попадали в повествование. Добавлена профилактика в планировании и консервативное удаление конкретного метатекста; оговорка о синтетических данных сохраняется на обложке.
- Указание доступа к полной таблице обрезалось третьей строкой подписи шаблона. Краткая подпись помещается в две строки.
- После сокращения презентации могли оставаться старые PNG/PDF. Экспорт удаляет устаревшие управляемые файлы после подготовки новой версии.
- Название варианта обещало отличия, даже когда экспорт совпадал. Теперь сравниваются фактические изображения и показывается предупреждение. Гарантия трёх различных дизайнов этим не вводится.

Обновлены 12 демонстрационных вариантов с резервными копиями и без вызовов модели: Education A/B/C — по 10 слайдов; VK Tech и WorkSpace — по 11; сторонний шаблон — по 9.
