# Задачи сервиса «Цифровой дизайнер презентаций»

Сервис живёт в `designer/` (Python). Слои: разбор, план, вёрстка, аудит, экспорт. Общие контракты в `designer/src/designer/contracts.py`, менять их можно только отдельной задачей. Java-сервис в `backend/` принимает звук и режет речь на смысловые фрагменты; живой режим зовёт тот же сборщик слайда, что и текстовый.

Правила для исполнителя:

- один файл, один владелец: трогать только файлы из раздела «Файлы» своей задачи;
- каждая полоса работает в своём рабочем дереве git и на своей ветке;
- гонять только свои тесты, полный набор идёт один раз перед слиянием;
- промпты и настройки моделей лежат файлами в `designer/skills`, в код не зашиваются;
- в коде нет имён выданных шаблонов, имён макетов и номеров слайдов: на финале будет незнакомый pptx;
- модели только с открытыми весами до 35B, по умолчанию `qwen/qwen3.8-27b` на локальном сервере.

## Волна 2: сборка слайда, после слияния волны 1

После слияния волны 1 полный набор тестов зелёный. Общий модуль размещения блоков `designer/src/designer/layout/units.py` написан заранее: им пользуются и вёрстка, и экспорт pptx, поэтому эти две задачи идут параллельно.

| Задача | Что даёт | Модель | Статус |
|---|---|---|---|
| [T-07](T-07-layout.md) | подбор паттерна, вместимость слотов, перекладка блоков, сцена | opus | в работе |
| [T-08](T-08-export-pptx.md) | pptx клонированием слайдов-образцов, все объекты родные | opus | в работе |
| [T-09](T-09-slot-writer.md) | скилл заполнения слотов под вместимость и скилл «фрагмент речи в слайд» | sonnet | в работе |
| [T-10](T-10-audit-contextual.md) | контекстные проверки по картинке слайда на модели, которая понимает изображения | sonnet | в работе |
| [T-11](T-11-convert.md) | pptx в PDF и в картинки слайдов, движки LibreOffice и PowerPoint | sonnet | в работе |

Что всплыло на волне 1 и ждёт своей задачи:

- встроенные шрифты шаблонов лежат в контейнере EOT со сжатием MicroType Express, в TTF они не извлекаются; в pptx шрифт сохраняется сам (слайды клонируются из исходника), для HTML нужен распаковщик либо запасной шрифт;
- типы слайдов по одной геометрии распознаются грубо (в шаблоне VK Tech нет ни одного «крупного числа» и «шагов», хотя на глаз они есть); уточнение типа по картинке слайда через модель стоит отдельной задачей после T-11.
