# T-22. Вёрстка: дефекты первой живой колоды

Модель: opus. Волна 4. Зависит от слитых T-18, T-19.

## Цель

Первая колода от брифа до pptx на живой модели (шаблон WorkSpace, 13 слайдов) выглядит родной для шаблона, но четыре вещи бросаются в глаза. Слово в разделителе рвётся посреди («Решени / е»): кегль 80 pt шире рамки. Заголовок наезжает на подзаголовок, когда занимает больше строк, чем в образце. На слайде-таймлайне остались пустые цветные полосы: это оформление блока, текста в нём нет. В кружках шагов «01» переносится на две строки, потому что образец рассчитан на одну цифру.

## Файлы

Только эти файлы, других не трогать:

- `designer/src/designer/layout/match.py`, `capacity.py`, `compose.py`, `scene.py`
- `designer/tests/layout/test_match.py`, `test_capacity.py`, `test_compose.py`, `test_scene.py`

`contracts.py` и `layout/units.py` не менять. Публичные сигнатуры не менять, необязательные параметры добавлять можно.

## Что сделать

1. Подгонка по самому длинному слову. Кегль слота подбирается так, чтобы самое длинное слово текста помещалось в ширину рамки целиком (ширина знака 0,52 кегля). Для слотов с кеглем крупнее самой крупной ступени заголовков (разделители, крупные числа) разрешён промежуточный кегль вне шкалы, но не меньше ступени `title`. Результат пишется в `fitted_size_pt`.
2. Заголовок и то, что под ним. Если после подгонки заголовок занимает больше строк, чем образец, и его набранные строки заходят на слот под ним, сначала заголовок опускается на ступень шкалы; если не помогло, текст слота под ним убирается (пустая строка), а фигура уходит в `remove_shape_ids`.
3. Пустые блоки оформления. Группа, у которой ни в одном блоке нет текстового слота, заполнена быть не может: если она не связана с заполненной группой, она целиком уходит в `remove_shape_ids`. Если связана, число её блоков приводится к числу блоков главной группы.
4. Короткие номера. В слот блока с ролью `number`, рассчитанный на один-два знака, номер ставится без ведущего нуля («1», а не «01»), когда иначе он не помещается в одну строку.
5. Подбор крупного числа учитывает длину числа: слот `number` должен вмещать значение из намерения при кегле не ниже ступени `title`, иначе паттерн получает штраф.
6. Подбор под таймлайн и шаги: паттерн, у которого главная группа не имеет текстовых слотов ни сама, ни через связанные группы, не берётся.

## Готовность

Из каталога `designer`:

```
python -m pytest tests/layout
```

Прежние проверки остаются зелёными. Новые на синтетических паттернах: слово из 12 знаков в рамке шириной 0,3 при кегле 80 pt получает кегль, при котором слово помещается; заголовок в три строки над подзаголовком либо опущен на ступень, либо подзаголовок убран, а наложения набранных строк нет; группа без текстовых слотов уходит в `remove_shape_ids`; номер «01» в слоте на один знак становится «1». На выданных шаблонах (фикстура `templates`): намерение `section` с заголовком «Реструктуризация» не даёт `layout.text_overflow` и кегль не ниже ступени `title`; план из восьми намерений из прежних тестов не даёт `layout.overlap`.

## Запреты

- Никаких имён шаблонов, макетов, номеров слайдов и текстов-образцов в коде.
- Модели и сеть не использовать.
- Полный набор тестов не гонять, только `tests/layout`.
