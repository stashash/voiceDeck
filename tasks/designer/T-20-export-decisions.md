# T-20. Экспорт pptx исполняет решения вёрстки; диаграммы и таблицы по теме слайда

Модель: sonnet. Волна 3. Зависит от слитых T-05, T-08 и от расширенных контрактов.

## Цель

Человек открывает pptx и видит тот же слайд, что в предпросмотре: лишние карточки убраны, диаграмма стоит на всю свободную область, заголовок не лезет на логотип, на тёмном шаблоне подписи осей светлые. Сейчас экспорт сам ничего не убирает и кегль не подгоняет: в сквозной колоде заголовок титула вылез за кадр, рядом с диаграммой остались пустые карточки образца, на тёмном фоне подписи диаграммы чёрные.

## Файлы

Только эти файлы, других не трогать:

- `designer/src/designer/export/pptx_deck.py`, `pptx_text.py`
- `designer/src/designer/viz/pptx_native.py`, `palette.py`
- `designer/tests/export/test_pptx_deck.py`, `test_pptx_text.py`
- `designer/tests/viz/test_chart.py`, `test_table.py`, `test_palette.py`

`contracts.py` уже расширен, менять его не надо: `SlideSpec.linked_unit_text`, `fitted_size_pt`, `viz_box`, `remove_shape_ids`. `layout/units.py` и `pptx_clone.py` не менять.

## Что сделать

1. `export_pptx` исполняет `SlideSpec` буквально:
   - фигуры из `remove_shape_ids` удаляются со слайда-клона;
   - связанные группы из `linked_unit_text` перекладываются и заполняются так же, как главная группа: те же `place_units` и `map_shape_box`, то же число блоков;
   - кегль из `fitted_size_pt` ставится всем фрагментам фигуры слота (для слотов блока во всех блоках);
   - диаграмма и таблица встают в `viz_box`; если его нет, действует прежнее правило с `viz_area_id`.
2. `set_text(shape, text, size_pt=None)`: необязательный кегль; автоподбор PowerPoint у фигуры выключается, когда кегль задан, чтобы размер не поплыл при открытии.
3. `add_chart` и `add_table` получают необязательный параметр `theme: "light" | "dark" = "light"`. Для тёмной темы подписи осей, легенда, подписи данных и текст таблицы берут светлый цвет текста из токенов (самый контрастный к фону слайда), линии сетки приглушённые светлые, строки таблицы без заливки либо с заливкой `surface`, если она тёмная. Выбор цвета делается по контрасту к фону, а не по имени роли.
4. Кегль подписей диаграммы и текста таблицы зависит от высоты рамки: для рамки выше 50 % слайда берётся ступень `body`, иначе `caption`. Высота строки шапки таблицы не больше полутора высот строки данных.
5. `export_pptx` передаёт тему паттерна в `add_chart` и `add_table`.

## Готовность

Из каталога `designer`:

```
python -m pytest tests/export/test_pptx_deck.py tests/export/test_pptx_text.py tests/viz
```

Прежние проверки остаются зелёными. Новые: фигуры из `remove_shape_ids` отсутствуют в итоговом слайде; связанная группа из четырёх блоков после перекладки на три блока содержит три набора фигур с центрами, совпадающими с главной группой; кегль из `fitted_size_pt` стоит у всех фрагментов фигуры; рамка диаграммы совпадает с `viz_box` с точностью 1 %; на тёмной теме цвет подписей осей имеет контраст к фону не ниже 4,5; шапка таблицы не выше полутора строк данных.

## Запреты

- Диаграмму и таблицу картинкой не вставлять.
- Цвета константами в коде не задавать, только из `Tokens`.
- Полный набор тестов не гонять, только свои файлы.
