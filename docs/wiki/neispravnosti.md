# Если не работает

| Что видно | Причина | Что сделать |
|---|---|---|
| `http://127.0.0.1:8090/health` отвечает `"model_ok":false` | сервер LM Studio не запущен | `pwsh scripts/start-models.ps1` |
| В Live-режиме «Модель загружается» | LM Studio выгрузил модель после часа простоя или после перезагрузки и грузит её по первому запросу; загрузка эмбеддингов при этом выгружает Qwen | `pwsh scripts/start-models.ps1`: обе модели закрепляются без срока |
| Контейнеры в состоянии `Exited (255)` | Docker перезапускался, а контейнеры собраны старым `compose.yaml` без политики перезапуска | `docker compose up -d` |
| В Live-режиме «Дизайнер недоступен» | нет ни одной дизайн-системы, или модель занята генерацией презентации и слайд не успел за 15 секунд | сделайте дизайн-систему из pptx в разделе «Дизайн-системы»; не выступайте, пока идёт генерация; причина в `docker compose logs designer` |
| Скрипт ждёт каждый запрос около 20 секунд | адрес `localhost`: на Windows запрос сначала уходит в IPv6, а порты открыты только на 127.0.0.1 | пишите `127.0.0.1` вместо `localhost` |
| После пересборки страница пустая | вкладка держит файлы прошлой сборки интерфейса | обновите страницу с очисткой кэша, Ctrl+F5 |
| Кнопка **Запись** не включает микрофон | браузер даёт микрофон только на `localhost` или по HTTPS, либо доступ запрещён | откройте `http://localhost:8088`, разрешите микрофон в адресной строке |
| Буквы на картинке слайда шире, чем в PowerPoint | картинки снимает LibreOffice и подставляет шрифт, которого у него нет | сверяйте вёрстку по pptx: он собран из родных фигур шаблона |
| Дизайн-система разбирается больше двух минут | модель описывает каждый образец по картинке, строго по одному запросу; ход виден на полосе «Модель описывает образцы» | дождитесь; `DESIGNER_DESCRIBE=0` выключает описание, но тогда плашки под фото, нарисованные в фоне макета, не распознаются |
| В настройках у Claude Code «не выполнен вход» | CLI установлен, но не вошёл в аккаунт | запустите `claude` в терминале, выполните `/login`, затем нажмите «Проверить» |

Журналы: `docker compose logs -f app` для речи, `docker compose logs -f designer` для вёрстки.
