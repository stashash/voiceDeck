# T-05. Родные диаграммы и таблицы PowerPoint в цветах шаблона

Модель: sonnet. Волна 1. Зависит только от `designer/src/designer/contracts.py`.

## Цель

Человек открывает скачанный pptx, щёлкает по диаграмме и правит данные в обычном окне PowerPoint. Цвета и шрифт диаграммы и таблицы взяты из загруженного шаблона. Слайд картинкой в ТЗ не засчитывается, а красивую подачу чисел кейсодержатель назвал частым запросом.

## Файлы

Только эти файлы, других не трогать:

- `designer/src/designer/viz/pptx_native.py`
- `designer/src/designer/viz/palette.py` (новый)
- `designer/tests/viz/test_chart.py`, `test_table.py`, `test_palette.py` (новые)

Сигнатуры `add_chart` и `add_table` заморожены. `contracts.py` не менять.

## Что сделать

1. `palette.py`: порядок цветов рядов из `Tokens`: `accent`, `accent_alt`, затем остальные цвета по убыванию `share`, без фона и цвета текста. Функция контрастного цвета текста для заливки.
2. `add_chart(slide, spec, box, slide_size_emu, tokens)`: диаграмма python-pptx (`column`, `bar`, `line`, `pie`, `donut`), рамка из долей слайда в EMU. Цвета рядов из палитры (у круговых по точкам), шрифт `body` из токенов, кегль подписей из ступени `caption` либо самой мелкой, легенда при двух и более рядах, подписи данных у круговых, название оси значений из `unit`, линии сетки приглушённым цветом. Больше пяти рядов это `ValueError`.
3. `add_table(slide, spec, box, slide_size_emu, tokens)`: родная таблица. Шапка заливкой `accent` с контрастным текстом, строки через одну заливкой `surface`, шрифт и кегль из токенов, колонки равной ширины. Больше 7 строк или 5 колонок это `ValueError`.

## Готовность

Из каталога `designer`:

```
python -m pytest tests/viz
```

Тесты создают пустую презентацию python-pptx, добавляют объект, сохраняют во временный файл, открывают заново и проверяют: на слайде есть диаграмма нужного типа с нужным числом рядов и категорий; заливка первого ряда равна `accent` из токенов; у таблицы текст ячеек и заливка шапки; рамка объекта совпадает с заданной с точностью до 1 %; шесть рядов и восемь строк дают `ValueError`.

## Запреты

- Диаграмму картинкой не вставлять.
- Цвета и шрифты константами в коде не задавать, только из `Tokens`.
- Полный набор тестов не гонять, только `tests/viz`.
