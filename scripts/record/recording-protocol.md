# Протокол записи калибровочного корпуса

Цель: 10–15 монологов по 10–20 минут с естественными сменами темы. Это единственный источник правды для калибровки порогов сегментации (T-S3, T-S10).

## Что записывать

| Стиль | Сколько | Пример |
|---|---|---|
| Лекция / доклад с планом | 4–5 | Рассказ по слайдам, явные переходы («итак», «следующий пункт») |
| Свободный монолог | 3–4 | Объяснение темы без плана, переходы неявные |
| Технический разбор | 3–4 | Пошаговый анализ кода/системы, переходы по подсистемам |

Требования:
- WAV mono 16 кГц 16-bit (OBS, Audacity, или ffmpeg -ar 16000 -ac 1 -sample_fmt s16).
- Русская речь, 1 спикер, минимум фонового шума.
- Темы должны реально меняться: минимум 3 явных перехода на монолог.

## Как размечать

1. Прогнать запись через VoiceDeck в MODE=live (транскрипт появится сам).
2. Экспортировать JSON сессии, извлечь массив sentences.
3. Открыть scripts/label/labeler.html, загрузить текст предложений.
4. Кликом расставить границы там, где «началась новая тема». Правило: граница там, где слушатель мог бы вставить новый слайд.
5. Скачать boundaries.tsv.

## Что НЕ делать

- Не размечать паузы как границы — только смену темы.
- Не подгонять под текущее поведение системы — размечаем «как должно быть».
- Не выбрасывать «неудачные» записи — они и есть калибровочный сигнал.
