# T-19. Вёрстка: качество подбора и решения для экспорта

Модель: opus. Волна 3. Зависит от слитых T-07 и от расширенных контрактов.

## Цель

Сквозная колода из восьми слайдов на трёх выданных шаблонах собралась, но на глаз до шаблона не дотягивает. Диаграмма и таблица встали в угол размером с почтовую марку. Крупное число набрано мелким текстом в карточке. На финальный слайд лёг образец с чужой диаграммой. У карточек пропал текст, когда в блоке паттерна был только заголовок. После этой задачи вёрстка сама решает всё, что влияет на вид слайда, и записывает решения в `SlideSpec`, а экспорт исполняет их буквально.

## Файлы

Только эти файлы, других не трогать:

- `designer/src/designer/layout/match.py`, `capacity.py`, `compose.py`, `scene.py`
- `designer/tests/layout/test_match.py`, `test_capacity.py`, `test_compose.py`, `test_scene.py`

`contracts.py` уже расширен, менять его не надо: `SlideSpec.linked_unit_text`, `fitted_size_pt`, `viz_box`, `remove_shape_ids`; `Pattern.purpose`, `needs_images`, `primary_group_id`; `RepeatGroup.linked_group_ids`; `Area.placeholder`. `layout/units.py` не менять.

## Что сделать

1. Подбор паттерна (`match.py`):
   - паттерн с `needs_images=True` не берётся, когда у намерения нет картинок (сейчас их нет никогда);
   - паттерн, у которого на слайде есть диаграмма, таблица или картинка-образец, не берётся под намерение без такой же визуализации: чужой образец на слайде останется;
   - точное совпадение числа блоков с числом пунктов ценится выше, чем перекладка; перекладка больше чем на два блока штрафуется;
   - слоты блока должны вмещать содержание пункта: пункту с заголовком и текстом нужен блок с двумя текстовыми слотами либо связанная группа; блок с одним слотом годится только пунктам без заголовка;
   - для `big_number` нужен слот с ролью `number`; для `thanks`, `section`, `title` нужен паттерн без групп и без визуализации;
   - под диаграмму или таблицу годится паттерн, где после удаления групп и образцов остаётся свободная рамка не меньше 40 % площади слайда.
2. Заполнение (`compose.py`):
   - главная группа из `primary_group_id`, связанные группы заполняются через `linked_unit_text` тем же числом блоков (номер в группу номеров, подпись в группу подписей);
   - группы, которые не заполнены, уходят в `remove_shape_ids` целиком, вместе с фигурами блоков;
   - заглушки под фото (`Area.placeholder`) уходят в `remove_shape_ids`;
   - `viz_box`: рамка под диаграмму или таблицу это область содержимого слайда ниже заголовка в пределах полей шаблона, за вычетом слотов, которые заполнены; всё, что лежит в этой рамке и не заполнено, уходит в `remove_shape_ids`;
   - `fitted_size_pt`: кегль каждого заполненного слота после подгонки по ступеням шкалы; заголовок, который не помещается и на самой мелкой ступени для заголовков, остаётся на ней, это найдёт аудит.
3. Сцена (`scene.py`) строится по тем же решениям: `remove_shape_ids` не попадают в сцену, диаграмма и таблица стоят в `viz_box`, кегли из `fitted_size_pt`, связанные группы перекладываются тем же `place_units`.

## Готовность

Из каталога `designer`:

```
python -m pytest tests/layout
```

Прежние проверки остаются зелёными. Новые проверки на выданных шаблонах (фикстура `templates`) с планом из восьми намерений (титул, три карточки с заголовком и текстом, четыре шага с номерами, крупное число, диаграмма, таблица, три пункта списка, финал):

- ни для одного слайда не выбран паттерн с `needs_images=True`;
- финал и титул стоят на паттернах без групп и без областей диаграммы, таблицы, картинки-образца;
- у слайдов с диаграммой и таблицей площадь `viz_box` не меньше 35 % слайда, рамка внутри полей, в сцене в этой рамке нет других элементов с текстом;
- у карточек ни один пункт не потерял текст: каждый `body` из плана есть в сцене;
- у шагов номера и подписи стоят на одной оси (центры совпадают с допуском 0,03);
- детерминированный аудит по сценам не даёт `layout.overlap`, `layout.out_of_bounds`, `integrity.placeholder_text`.

## Запреты

- Никаких имён шаблонов, макетов, номеров слайдов и текстов-образцов в коде.
- Модели и сеть не использовать.
- Полный набор тестов не гонять, только `tests/layout`.
