# T-S12 — Калибровочный стенд: запись + разметка + метрики

**Epic:** E-S · **Risk:** low · **Pipeline:** solo · **Human gate:** none
**Зависит от:** —

## Контекст

Без 10–15 размеченных монологов и расчёта Pk/WindowDiff/F1 нельзя ни откалибровать T-S3/T-S10, ни подтвердить, что правки работают. Это «люди + время», не код, но код-инфра нужна.

## Что меняется

| Файл | Назначение |
|---|---|
| `scripts/record/recording-protocol.md` | NEW. Инструкция: 10–15 монологов по 10–20 минут, разные стили (лекция, разбор, диалог). WAV 16 кГц mono. |
| `scripts/record/label-format.md` | NEW. Формат разметки: `<start_ms>\t<text>` + отдельный файл `<start_ms>\t<boundary>` для границ. |
| `scripts/label/labeler.html` | NEW. Минимальный браузерный тул: загружает WAV, показывает транскрипт, позволяет расставлять границы кликом, экспорт в label-format. |
| `scripts/calibrate/calibrate.mjs` | NEW. Node-скрипт: читает размеченный корпус + прогоняет через `bge-m3-embed` (Ollama), вычисляет Pk / WindowDiff / F1 (±1), гистограммы косинусов. |
| `scripts/calibrate/calibrate.sh` | NEW. Запуск: `./calibrate.sh voicedeck-eval/` — загоняет корпус через пайплайн и печатает отчёт. |

## Acceptance

- `scripts/label/labeler.html` открывается в браузере, можно расставить границы, скачать `.tsv`.
- `scripts/calibrate/calibrate.mjs` запускается на 1+ файле, печатает метрики.
- README в `scripts/calibrate/` объясняет, как интерпретировать Pk/WD/F1.
- Метрика, которая покажет, что правки работают: **F1 ≥ 0.7** на калибровочном корпусе после T-S1+T-S3+T-S10.

## Что НЕ делать

- Не делать UI навороченный — это утилита.
- Не делать TTA (text-to-audio alignment) автоматический — только ручная разметка.
