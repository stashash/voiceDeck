# T-23. План и текст: диаграммы из чисел, обрезка по слову

Модель: sonnet. Волна 4. Зависит от слитых T-04, T-09.

## Цель

В первой живой колоде бриф содержал ряд «инцидентов было 9, стало 2» и долю «затраты выросли на 12 %», а план не предложил ни диаграммы, ни таблицы: числа ушли в текст карточек. Кейсодержатель назвал красивую подачу числовых данных частым запросом. И один заголовок оказался обрезан посреди слова: «Потоковая загрузка быстрее и ста».

## Файлы

Только эти файлы, других не трогать:

- `designer/src/designer/plan/planner.py`, `designer/src/designer/plan/writer.py`
- `designer/skills/plan-deck/skill.yaml`, `prompt.md`
- `designer/skills/fill-slots/skill.yaml`, `prompt.md`
- `designer/tests/plan/test_planner.py`, `test_writer.py`

## Что сделать

1. Промпт `plan-deck`: когда в брифе есть два и больше сопоставимых числа (было и стало, план и факт, ряд по периодам), слайд получает тип `chart` с `ChartSpec` из этих чисел; одно главное число идёт типом `big_number`; три и больше показателей с двумя состояниями идут типом `table`. Числа только из брифа. В плане на 10–15 слайдов не меньше одного слайда с диаграммой или таблицей, если в брифе есть числа. Версия скилла повышается.
2. Проверка кодом в `make_plan`: в брифе есть пара сопоставимых чисел, а в плане нет ни `chart`, ни `table`, ни `big_number`: один повтор с этим замечанием.
3. `writer.py`: сокращение текста, который не уложился в лимит и после повтора. Порядок: по границе предложения, затем по границе слова. Обрыв посреди слова запрещён. После сокращения с конца убираются висящие союзы, предлоги и знаки («и», «в», «на», «с», запятая, тире). Если после этого осталось меньше половины лимита, текст сокращается по границе слова без чистки хвоста.
4. Промпт `fill-slots`: заголовок пишется сразу под лимит, с запасом в 10 %, законченной фразой. Версия скилла повышается.

## Готовность

Из каталога `designer`:

```
python -m pytest tests/plan
```

Живых вызовов нет, сервер подменяется через `httpx.MockTransport`. Проверки: бриф с «с 9 до 2» и план без визуализации дают повтор с замечанием; текст «Потоковая загрузка быстрее и стабильнее пакетной» при лимите 32 сокращается до «Потоковая загрузка быстрее», а не до обрыва слова; хвост «и» и запятая убираются; версии обоих скиллов выросли, хеш изменился.
