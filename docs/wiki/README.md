# Вики voiceDeck

voiceDeck делает из pptx дизайн-систему и собирает по ней слайды двумя путями. По брифу выходит презентация в трёх вариантах вёрстки с проверкой и выгрузкой в pptx, PDF и HTML. В Live-режиме слайды появляются вслед за речью спикера.

| [Агенты](agenty.md) | Claude Code, Codex, Cursor Agent, OpenCode или Qwen в LM Studio: подключить и назначить |
| [Презентация по брифу](prezentaciya-po-brifu.md) | дизайн-система из pptx, генерация, правка слайда, выгрузка |
