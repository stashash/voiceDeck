# Примеры источников фирменного стиля

Все примеры созданы для VoiceDeck, не являются брендбуком сторонней компании.

| Файл в `frontend/public/brandbooks` | Что проверяет |
|---|---|
| `local-tokens.json` | Цветовые роли, Play, размеры шрифта, поля, оформление осей и легенды, сетка, правила логотипа. |
| `local-brandbook.pdf` | PDF с явными HEX/RGB, типографикой, размерами, полями и встроенным растровым логотипом. |
| `local-brandbook.zip` | Папка токенов, логотипа и образца слайда в ZIP. |
| `local-assets-only.zip` | Папка изображений без токенов: извлечение палитры и однозначно названного логотипа. |
| `local-demo.fig` | Реальный локально закодированный бинарный Figma/Kiwi-файл, а не переименованный JSON. |

Воспроизведение: `python examples/brandbooks/build_examples.py`, затем из `frontend` — `node scripts/create-demo-fig.mjs`. Генератор PDF/ZIP использует Pillow, ReportLab; тестовый XLSX — openpyxl. Генератор `.fig` использует закреплённые зависимости frontend.

В интерфейсе: **Дизайн-системы → выбрать систему → Брендбук и токены → загрузить файл**. По умолчанию приоритет у брендбука. Его можно переключить на шаблон; исходные правила и палитра шаблона сохраняются. При удалении брендбука восстанавливается исходный шаблон.

Play распространяется по SIL OFL 1.1; лицензия находится в `designer/fonts/OFL.txt`. Шрифт встроен в образ сервиса и HTML, поэтому демонстрация не зависит от Google Fonts или установленного шрифта на компьютере зрителя.

## Границы импорта

- PDF: явные токены, доступный текст, векторные RGB-операторы, метаданные шрифтов и встроенные растровые изображения. Сканированный гайд без текстового слоя не распознаётся OCR и не должен считаться разобранным автоматически.
- Figma: бинарный `.fig` разбирается локально в отдельном worker без `eval` и загрузки кода из документа. Предусмотрены лимиты размера, распаковки, рекурсии и времени. Неподдерживаемые версии возвращают ошибку; импорт плагинов, облачных библиотек и всех возможностей Figma не заявляется.
- Папки передаются ZIP-архивом. Токены приоритетнее оценки цветов по изображениям. Логотип определяется по явному правилу либо однозначному имени файла; неоднозначность не разрешается случайным выбором.
- Автоматическое извлечение не гарантирует понимания любого естественного языка гайдлайна. Перед генерацией интерфейс показывает действительно применённые поля и предупреждения.
