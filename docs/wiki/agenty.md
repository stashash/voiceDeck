# Агенты: мост на хосте и выбор агента

Сервис `designer` работает в Docker и не видит CLI на хосте, поэтому CLI-агенты (Claude Code,
Codex, Cursor Agent, OpenCode) запускает отдельный процесс на машине пользователя — мост
`scripts/agent_bridge.py`. Только стандартная библиотека Python, без установки зависимостей.

## 1. Запустите мост

1. В корне репозитория выполните:

   ```powershell
   python scripts/agent_bridge.py
   ```

2. Проверьте вывод: `мост агентов слушает http://127.0.0.1:8095`. Оставьте окно открытым —
   мост нужен всё время, пока используются CLI-агенты.

Мост слушает только `127.0.0.1:8095` и виден лишь этой машине. Он находит CLI-агентов в PATH
и запускает их неинтерактивно; каких CLI сейчас нет в PATH, видно в списке агентов на следующем
шаге как `found: false`.

## 2. Укажите сервису designer адрес моста

1. В `.env` (или в окружении перед `docker compose up`) убедитесь, что задана переменная:

   ```ini
   DESIGNER_AGENT_BRIDGE_URL=http://host.docker.internal:8095
   ```

   Это значение уже стоит по умолчанию в `compose.yaml`, менять его нужно только если мост
   запущен на другом порту.

2. Перезапустите сервис `designer`, если он уже был поднят:

   ```powershell
   docker compose up -d designer
   ```

## 3. Проверьте связь с агентом

1. Откройте в приложении «Настройки → Агенты и модели» (`#/settings`).
2. Найдите нужный CLI в списке (или локальную модель LM Studio — для неё мост не нужен).
3. Нажмите «Проверить»: агент отвечает за 30 секунд, показывает, принимает ли он картинки,
   и найден ли вообще в PATH на машине.

То же самое напрямую, без интерфейса:

```powershell
curl http://127.0.0.1:8095/agents
curl -X POST http://127.0.0.1:8095/agents/claude/check
```

## 4. Назначьте агента на задачу

1. В «Настройки → Агенты и модели» выберите, кто делает презентации («Колода»), кто отвечает
   в Live-режиме («Live») и кто описывает образцы дизайн-системы по картинке («Описание»).
2. Выбор сохраняется сразу и переживает перезапуск сервиса (файл
   `data/settings/agents.json` в томе `designer`).

Для описания образцов картинкой годится только агент с `images: true` в проверке (сейчас это
Codex и OpenCode — у Claude Code и Cursor Agent в `--help` этой версии нет документированного
способа передать файл картинки).
