# T-03. Аудит: детерминированные проверки

Модель: sonnet. Волна 1. Зависит только от `designer/src/designer/contracts.py`.

## Цель

После генерации человек видит на слайде отмеченные огрехи: текст вылез из рамки, цвет не из палитры, семь пунктов вместо шести. Он выбирает, что чинить. Проверки на одном и том же слайде всегда дают один и тот же результат.

## Файлы

Только эти файлы, других не трогать:

- `designer/src/designer/audit/deterministic.py`
- `designer/src/designer/audit/checks_layout.py`, `checks_template.py`, `checks_density.py`, `checks_integrity.py` (новые)
- `designer/tests/audit/test_layout.py`, `test_template.py`, `test_density.py`, `test_integrity.py`, `test_registry.py` (новые)

Сигнатура `run_checks` заморожена. `contracts.py` не менять.

## Что сделать

Вход: список `Scene` и `DesignSystem`. Выход: список `Finding` с `kind="deterministic"`, отсортированный по слайду, проверке и элементу. Реестр `CHECKS` в `deterministic.py`: у каждой проверки `id`, группа, название по-русски, функция.

Вёрстка:
- `layout.out_of_bounds` элемент вышел за границы слайда;
- `layout.overlap` два содержательных блока наложились (текст внутри своей подложки наложением не считается);
- `layout.text_overflow` текст не помещается в рамку: оценка от числа знаков, кегля и размера рамки (ширина знака 0,52 кегля, интерлиньяж 1,2);
- `layout.in_margins` содержимое зашло в поля из `tokens.margins`;
- `layout.off_guides` левый край блока не совпал ни с одной направляющей (допуск 0,01);
- `layout.image_aspect` картинка растянута: пропорции рамки расходятся с пропорциями ассета больше чем на 3 %.

Шаблон:
- `template.font` шрифт не из токенов либо гарнитур на слайде больше двух;
- `template.type_scale` кегль не из шкалы (допуск 0,5 pt);
- `template.color` цвет текста или заливки не из палитры (допуск 8 по каждому каналу);
- `template.pattern` `pattern_id` сцены отсутствует в дизайн-системе;
- `template.contrast` контраст текста к фону под ним ниже 4,5:1 по формуле WCAG.

Плотность:
- `density.bullets` больше 6 пунктов; `density.bullet_words` пункт длиннее 15 слов;
- `density.table` таблица больше 7 строк или 5 колонок; `density.series` больше 5 рядов на диаграмме;
- `density.fill` содержимое занимает меньше четверти или больше трёх четвертей слайда.

Целостность:
- `integrity.placeholder_text` остался текст-заглушка: lorem ipsum, XXX, TODO, «вставьте текст», «заголовок», «текст»;
- `integrity.empty` пустой слайд или слайд с одним заголовком;
- `integrity.chart_labels` у диаграммы нет категорий, имён рядов или единиц;
- `integrity.duplicate` два слайда с одинаковым текстом после нормализации.

У каждой находки `element_ids`, `box`, `message` по-русски, `fixable` и `fix_hint` там, где починка механическая (уменьшить кегль до ступени шкалы, заменить цвет ближайшим из палитры, сдвинуть к направляющей).

## Готовность

Из каталога `designer`:

```
python -m pytest tests/audit
```

Для каждой проверки два теста на синтетических сценах: огрех найден, чистая сцена молчит. `test_registry.py` проверяет, что идентификаторы уникальны, что два прогона подряд дают одинаковый результат и что чистая сцена из пяти слайдов даёт пустой список.

## Запреты

- Модели и сеть не использовать.
- Полный набор тестов не гонять, только `tests/audit`.
