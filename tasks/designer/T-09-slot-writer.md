# T-09. Скилл заполнения слотов под вместимость

Модель: sonnet. Волна 2. Зависит от контрактов и слоя модели (T-04).

## Цель

Модель пишет текст слайда сразу под рамки выбранного паттерна: заголовок не длиннее, чем помещается, у каждой карточки короткий заголовок и текст по размеру. Человек не видит обрезанных фраз и вылезших строк. Этот же скилл в живом режиме превращает фрагмент речи в слайд, поэтому ответ должен быть коротким и быстрым.

## Что сделать

1. `fill_slots(intent: SlideIntent, limits: dict[str, int], unit_limits: dict[str, int], n_units: int, client: LlmClient) -> SlideIntent`. На вход идёт намерение слайда из плана и лимиты знаков по ролям слотов (`title`, `subtitle`, `body`, у блока `heading`, `body`, `number`). На выходе то же намерение с текстами, которые укладываются в лимиты, и ровно `n_units` пунктами. Схема ответа строится кодом, `maxLength` в схеме равен лимиту.
2. Проверка кодом после ответа: длины, число пунктов, числа только из исходного намерения. Нарушение: один повтор с перечнем нарушений. Осталось нарушение по длине: текст сокращается по границе предложения или слова, без многоточия.
3. `speech_to_slide(chunk_text: str, kinds: list[SlideKind], client: LlmClient) -> SlideIntent`: фрагмент устной речи превращается в намерение слайда. Тип выбирается из переданного списка (это типы, которые есть в загруженной дизайн-системе). Только содержание фрагмента, без новых фактов и чисел. Для приветствия и технической реплики возвращается намерение с пустым заголовком: слайд не нужен.
4. Параметры запроса живут в `skill.yaml` и уходят в `complete_json(..., params=skill.params)`. Для обоих скиллов `reasoning_effort: none`. Для `speech-to-slide` `max_tokens: 400`, `temperature: 0.2`.
5. Промпты по-русски. Правила из ТЗ: заголовок это вывод, а не тема; слайд пересказывается одним предложением; пункт не длиннее 15 слов; никакого служебного текста, реплик и кусков промпта; язык ответа совпадает с языком входа.

## Готовность

Из каталога `designer`:

```
python -m pytest tests/plan/test_writer.py
```

Живых вызовов нет, сервер подменяется через `httpx.MockTransport`. Тесты проверяют: `maxLength` в схеме равен лимитам; параметры скилла уходят в тело запроса; слишком длинный ответ даёт повтор, затем сокращение по границе слова; число пунктов приводится к `n_units`; число, которого не было во входе, убирается; пустой заголовок у `speech_to_slide` возвращается как «слайд не нужен».
