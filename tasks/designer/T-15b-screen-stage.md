# T-15b. Экран «Сцена»: пульт спикера и окно зала (рабочий прототип)

Модель: sonnet. Волна 5. Зависит от слитого T-14.

Это рабочий прототип, чтобы живой режим можно было показать на видео. Бриф и макет по правилам владельца для интерфейсов идут следом; состав взят из `docs/design/ui-requirements.md`.

## Цель

Спикер выбирает дизайн-систему, включает микрофон и говорит. В окне зала на весь экран идут слайды в стиле загруженного шаблона и строка субтитров. На ноутбуке у спикера пульт: текущий слайд, следующий черновик, транскрипт, две клавиши.

## Файлы

Только эти файлы, других не трогать:

- `frontend/src/stage/StagePage.tsx`, `AudiencePage.tsx`, `useSession.ts`, `stage.css` (новые)
- `frontend/src/stage/useSession.test.ts` (новый)

Маршруты уже заведены в `frontend/src/router.tsx`. Транспорт, микрофон и редьюсер событий уже есть: `frontend/src/transport.ts`, `frontend/src/store.ts`. Читать и звать их можно, менять нельзя.

## Что сделать

1. `useSession.ts`: создание сессии, подключение `Transport`, микрофон, состояние из `reduce`. Логика та же, что в `main.tsx`, вынесенная в хук без копирования вёрстки. Команда смены дизайн-системы `{"type":"design_system","id":…}` после подключения. В демо-режиме (без весов распознавания) текст уходит командой `text`.
2. `StagePage.tsx` (пульт): выбор дизайн-системы из списка сервиса `designer` (`GET /design-systems`, адрес из `import.meta.env.VITE_DESIGNER_URL`), кнопка записи, текущий зафиксированный слайд, рядом черновик последнего фрагмента, живой транскрипт с хвостом, кнопка «Зал» открывает окно зала (`window.open` на маршрут зала с id сессии). Клавиши: пробел фиксирует черновик как текущий слайд раньше срока, Backspace убирает последний слайд с экрана зала. В демо-режиме поле ввода текста вместо микрофона.
3. `AudiencePage.tsx` (зал): только слайд на весь экран и строка субтитров внизу. Состояние получает от пульта через `BroadcastChannel` с id сессии: текущий слайд (`html` из события `slide`), субтитры (последняя финальная фраза и живой хвост). Слайд показывается в `iframe` с `srcdoc` и `sandbox`, смена слайда плавным проявлением 300 мс. Клавиша F открывает полный экран. Черновой слайд в зал не идёт, пока пульт его не зафиксировал либо не пришло подтверждение фрагмента (`status: "confirmed"`).
4. Слайд без `html` (старый режим `sketch`) показывается запасной вёрсткой: заголовок и пункты.
5. Значки из `lucide-react`, подписи одним словом, пояснения в подсказках, без марки и версии в углах.

## Готовность

Из каталога `frontend`: `npm ci`, затем `npm run build` и `npm test`. Сборка без ошибок типов. `useSession.test.ts` проверяет на подменённом транспорте: событие `slide` с `html` попадает в состояние; черновик не уходит в канал зала до фиксации; Backspace убирает последний слайд из канала.
