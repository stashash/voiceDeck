# T-06. Экспорт в HTML разметкой

Модель: sonnet. Волна 1. Зависит только от `designer/src/designer/contracts.py`.

## Цель

Человек открывает один HTML-файл без интернета и листает презентацию стрелками: шрифт шаблона, фоны, диаграммы на месте, текст выделяется мышью. Этот же рендер покажет слайды на полном экране в живом режиме и даст PDF через печать браузера.

## Файлы

Только эти файлы, других не трогать:

- `designer/src/designer/export/html.py`
- `designer/src/designer/export/svg_chart.py` (новый)
- `designer/tests/export/test_html.py`, `test_svg_chart.py` (новые)

Сигнатура `render_deck` заморожена. `contracts.py` не менять.

## Что сделать

1. Каждая `Scene` это `<section class="slide">` с пропорциями из `ds.slide_size_emu`. Элементы стоят абсолютно, координаты и размеры в процентах от слайда, порядок по `z`.
2. Кегль переводится в единицы контейнера, чтобы слайд масштабировался целиком: размер в pt делится на ширину слайда в pt и умножается на 100 `cqw`.
3. Токены дизайн-системы идут переменными CSS в `:root`. Шрифты пакета подключаются через `@font-face` и встраиваются base64, картинки пакета тоже base64. Внешних ссылок в файле нет: ни CDN, ни шрифтов из сети.
4. Текст это настоящий текст с экранированием HTML. Таблица это `<table>`. Диаграмма это встроенный SVG из `svg_chart.py`: `column`, `bar`, `line`, `pie`, `donut`, цвета рядов из токенов в том же порядке, что в pptx (accent, accent_alt, затем по убыванию доли), подписи категорий, легенда при двух и более рядах, единицы.
5. Фон слайда: `background_asset` картинкой на весь кадр либо `background_color`.
6. Листание стрелками и пробелом, клавиша F открывает полный экран, номер слайда в адресе после решётки. Скрипт встроен в файл.
7. Печать: один слайд на страницу в размер слайда, без полей, фоны печатаются.

## Готовность

Из каталога `designer`:

```
python -m pytest tests/export
```

Тесты собирают синтетическую колоду из трёх сцен с временным пакетом (картинка 2×2 пикселя, без шрифта) и проверяют разбором через `lxml.html`: три секции; текст на месте; строка `<script>alert(1)</script>` в тексте слайда экранирована; у диаграммы есть `<svg>` с числом столбцов по данным; таблица с нужным числом строк; в файле нет `http://` и `https://`; есть `@media print`.
