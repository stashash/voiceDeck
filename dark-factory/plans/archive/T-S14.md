# T-S14 — Frontend: badge «Пропущено по квоте»

**Epic:** E-S · **Risk:** low · **Pipeline:** solo · **Human gate:** none
**Зависит от:** —

## Контекст

Сейчас `slide {title: null, source: "quota"}` показывается клиенту как пустой слайд. Пользователь думает «баг». Нужно явное отображение.

## Что меняется

- `frontend/src/main.tsx` — в slide-preview bottom добавить ветку для `slide?.source === 'quota'`:
  ```
  СЛАЙД ПРОПУЩЕН ПО КВОТЕ · 45 с между темами
  ```
- `frontend/src/style.css` — стиль `.quota-badge` (жёлтый/нейтральный фон, иконка).
- `Slide` тип в `store.ts` уже имеет `source: string` — без изменений.

## Acceptance

- При `source === "quota"` показывается badge вместо пустого превью.
- При `source === "sketch"` / `"extractive-demo"` / `"local-llm"` — поведение как было.
- На мобильном (≤800px) badge виден.
- Кликабельно — badge открывает подсказку с timestamp следующего слайда (если есть).
