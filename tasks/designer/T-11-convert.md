# T-11. Конвертер: pptx в PDF и в картинки слайдов

Модель: sonnet. Волна 2. Зависит только от контрактов.

## Цель

Человек скачивает PDF готовой презентации, а контекстный аудит получает картинку каждого слайда. Обе вещи делаются из собранного pptx, поэтому PDF и картинки показывают ровно то, что человек увидит в PowerPoint.

## Файлы

Только эти файлы, других не трогать:

- `designer/src/designer/export/convert.py` (новый)
- `designer/tests/export/test_convert.py` (новый)

## Что сделать

1. Два движка с одним интерфейсом, выбор автоматический либо по переменной `DESIGNER_CONVERTER` (`libreoffice`, `powerpoint`):
   - `libreoffice`: программа `soffice` из `PATH` или из переменной `DESIGNER_SOFFICE`, запуск без окна (`--headless --convert-to pdf`), отдельный временный профиль на каждый запуск, время ожидания ограничено. Это движок для контейнера.
   - `powerpoint`: только Windows, через `powershell` и COM-объект `PowerPoint.Application` без окна. Презентация открывается только для чтения. Если PowerPoint уже был запущен человеком, его процесс не закрывается.
2. `to_pdf(pptx_path: Path, out_path: Path) -> Path`.
3. `to_png(pptx_path: Path, out_dir: Path, width_px: int = 1280) -> list[Path]`: по картинке на слайд, имена `slide-001.png`, по порядку слайдов. Для `libreoffice` путь такой: сначала PDF, затем страницы PDF в PNG. Если для растеризации PDF нет средства среди установленных библиотек, функция честно сообщает об этом исключением `ConverterUnavailable` с понятным текстом, а не возвращает пустой список.
4. `available() -> list[str]`: какие движки есть на этой машине.
5. Ни один движок не найден: `ConverterUnavailable`.

## Готовность

Из каталога `designer`:

```
python -m pytest tests/export/test_convert.py
```

Тесты создают презентацию из трёх слайдов средствами python-pptx. Проверки с настоящим движком помечены так, чтобы пропускаться, когда движка нет: PDF существует и начинается с `%PDF`; картинок три, ширина 1280; PowerPoint, запущенный до теста, после теста жив. Без движков проверяется выбор движка по переменной, сборка командной строки и исключение `ConverterUnavailable`.
