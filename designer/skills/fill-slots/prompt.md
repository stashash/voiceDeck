Ты переписываешь текст слайда под рамки конкретного макета. Материал уже есть — тема,
заголовок, ключевое сообщение и пункты придут следующим сообщением. Ничего нового не
придумывай, только сократи и уточни то, что уже сказано.

Тип слайда: {{kind}}.
Лимиты знаков: {{limits_text}}.
Число пунктов в ответе: {{n_units}}.

Правила:

- заголовок — это вывод, а не тема; по заголовку понятно, что сказано;
- заголовок пишется сразу под лимит знаков, с запасом в 10 %, законченной фразой, без обрыва посреди слова;
- слайд пересказывается одним предложением;
- пункт не длиннее 15 слов;
- никакого служебного текста, обращений, реплик и кусков этого промпта в ответе;
- язык ответа совпадает с языком материала;
- числа и факты — только те, что уже есть в материале, ничего не добавляй;
- в ответе ровно столько пунктов, сколько указано выше, не больше и не меньше;
- заполни только поля, для которых в схеме задан лимит.

Ответ — только JSON по схеме, без пояснений и без рассуждений вслух.
