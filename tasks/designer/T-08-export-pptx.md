# T-08. Экспорт в pptx клонированием слайдов-образцов

Модель: opus. Волна 2. Зависит от контрактов, пакета дизайн-системы (T-01, T-02), диаграмм и таблиц (T-05) и общего модуля `designer/src/designer/layout/units.py`.

## Цель

Человек скачивает pptx, открывает его в PowerPoint и видит слайды, родные для загруженного шаблона: тот же фон, те же карточки, тот же шрифт. Каждый объект выделяется, двигается и правится. По ТЗ слайд, выгруженный одной картинкой, не засчитывается.

## Файлы

Только эти файлы, других не трогать:

- `designer/src/designer/export/pptx_clone.py` (новый)
- `designer/src/designer/export/pptx_text.py` (новый)
- `designer/src/designer/export/pptx_deck.py` (новый)
- `designer/tests/export/test_pptx_clone.py`, `test_pptx_text.py`, `test_pptx_deck.py` (новые)

`contracts.py`, `layout/units.py`, `viz/pptx_native.py` и модули разбора не менять. Читать их и звать можно.

## Что сделать

1. `pptx_clone.py`: `clone_slide(prs, source_index) -> slide`. python-pptx копировать слайды не умеет. Нужен новый слайд на том же макете, глубокая копия дерева фигур и перенос связей: картинки, гиперссылки, встроенные объекты. Идентификаторы связей в скопированном XML переписываются на новые. Фон слайда копируется. Заметки не копируются.
2. `pptx_text.py`: `set_text(shape, text)`. Оформление первого фрагмента первого абзаца сохраняется (шрифт, кегль, цвет, начертание), остальные фрагменты и абзацы убираются, перевод строки в тексте даёт новый абзац с тем же оформлением. Пустая строка очищает фигуру, сама фигура остаётся.
3. `pptx_deck.py`: `export_pptx(specs: list[SlideSpec], ds: DesignSystem, package_dir: Path, out_path: Path) -> Path`.
   - Открыть `source.pptx` пакета. Для каждой `SlideSpec` клонировать слайд `pattern.source_slide`.
   - Текст слотов из `slot_text` по `Slot.shape_id`.
   - Блоки: нужное число это длина `unit_text`. Рамки блоков из `place_units(group, n)`. Фигуры существующих блоков переносятся через `map_shape_box` (картинки и значки с `keep_size=True`). Лишние блоки удаляются вместе со всеми своими фигурами. Недостающие получаются копией фигур последнего блока образца. Текст слотов блока ставится по соответствию: фигура i-го блока с той же рамкой относительно блока, что и у `unit_slots` первого блока.
   - Диаграмма и таблица: `add_chart` и `add_table` из `designer.viz.pptx_native` в рамку области `viz_area_id`. Фигуры образца, лежащие в этой области, удаляются.
   - Заметки докладчика из `SlideSpec.notes`.
   - После сборки исходные слайды удаляются, остаются только собранные, в порядке `specs`. Макеты, мастера и встроенные шрифты сохраняются.
4. Файл обязан открываться: после сохранения прочитать его заново через python-pptx. Осиротевшие части слайдов после удаления не должны ломать пакет.

## Готовность

Из каталога `designer`:

```
python -m pytest tests/export/test_pptx_clone.py tests/export/test_pptx_text.py tests/export/test_pptx_deck.py
```

Тесты идут на выданных шаблонах (фикстура `templates`, пакет собирается через `build_package` во временный каталог, `SlideSpec` пишутся руками по паттернам из манифеста) и проверяют:

- клон слайда с картинками открывается заново, число картинок и текстов совпадает с образцом;
- `set_text` сохраняет шрифт, кегль и цвет первого фрагмента;
- колода из пяти слайдов по паттернам с группой: три блока вместо исходного числа, пять блоков там, где `max_units` позволяет; у итогового слайда число фигур блоков равно числу блоков, умноженному на число фигур одного блока; рамки блоков совпадают с `place_units` с точностью 0,005;
- в итоговом файле ровно пять слайдов, исходных слайдов нет, образцовых текстов нет;
- слайд с диаграммой содержит родную диаграмму (`has_chart`), а не картинку;
- ни один слайд не состоит из единственной картинки на весь кадр;
- сторонний pptx (фикстура `foreign_pptx`) проходит тот же путь без исключений;
- колода из 15 слайдов собирается быстрее 60 секунд.

## Запреты

- Слайд или его часть картинкой не рендерить.
- Никаких имён шаблонов, макетов, номеров слайдов и текстов-образцов в коде, номера допустимы только в тестах.
- Полный набор тестов не гонять, только свои три файла.
